# Xoard

Xoard — нативный саундборд для Windows: записывает звуки (по дорожкам: Discord, игра, голос) и проигрывает
их «в микрофон» через виртуальный кабель [VB-CABLE](https://vb-audio.com/Cable/), чтобы их
слышали в Discord и играх.

> Статус: **версия 1.1** — новый дизайн и автообновление. Push-to-talk пока отложен.

## Установка

**[Скачать XoardApp-win-Setup.exe](https://github.com/xaxaxage/Xoard/releases/latest/download/XoardApp-win-Setup.exe)** —
эта ссылка всегда ведёт на последнюю версию, её можно просто отправить другу.

- Ставится в `%LOCALAPPDATA%\XoardApp` за пару секунд, права администратора и .NET не нужны;
  ярлыки — в меню «Пуск» и на рабочем столе.
- Установщик не подписан сертификатом, поэтому Windows при первом запуске может показать
  «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
- Ещё нужен бесплатный [VB-CABLE](https://vb-audio.com/Cable/) — Xoard подскажет, если его нет, а окно
  «Как настроить Discord» объяснит настройки Discord.
- **Обновления.** Xoard сам проверяет новые версии (при запуске и раз в 6 часов) и показывает
  «Вышла версия X — Обновить». Скачивает и ставит только по кнопке (обычно это мегабайт-другой),
  потом перезапускается. Звуки, клавиши и настройки остаются. Настройки → «Обновления» —
  проверить вручную, выключить проверку, скопировать ссылку для друга.
- **Удалить** — «Параметры Windows» → «Приложения» → Xoard. Звуки (`Документы\Xoard\Sounds`) и
  настройки (`%LOCALAPPDATA%\Xoard`) остаются.
- Раньше Xoard ставился скриптом `install.cmd` в `%LOCALAPPDATA%\Programs\Xoard`. Чтобы перейти на
  установщик: закройте Xoard, выполните `.\install.cmd uninstall`, потом запустите Setup.

### Выпуск новой версии (для разработчика)

1. Закоммитить и запушить изменения (`git push`).
2. `.\release.cmd 1.2.0` — номер больше прошлого. Скрипт собирает программу и сервер для Claude,
   упаковывает их Velopack (`dotnet tool run vpk`, версия закреплена в `dotnet-tools.json`) и
   выкладывает выпуск `v1.2.0` в GitHub Releases. Нужен вход в GitHub CLI (`gh auth login`).
3. У всех, кто поставил Xoard, появится «Вышла версия 1.2.0».

### Переименование: Soundboard → Xoard

Раньше программа называлась Soundboard. При первом запуске Xoard сам переносит
`Документы\Soundboard` → `Документы\Xoard` (звуки) и `%LOCALAPPDATA%\Soundboard` → `%LOCALAPPDATA%\Xoard`
(настройки и клавиши), а запись автозапуска — на новое имя. Если старую папку переместить
нельзя, файлы копируются, старые остаются на месте.

В Claude Desktop нужно поправить конфиг: сервер теперь `Xoard.Mcp.exe` (ключ `"xoard"`),
старый `Soundboard.Mcp.exe` с Xoard не работает.

## Claude Desktop (MCP)

Xoard.Mcp — MCP-сервер (stdio). Claude Desktop запускает его сам, а он передаёт команды
в открытое приложение Xoard по named pipe `Xoard.Control` (только для вашего пользователя Windows).

1. Сервер едет вместе с программой. При каждом запуске Xoard кладёт его копию в постоянное место —
   `%LOCALAPPDATA%\Xoard\mcp\Xoard.Mcp.exe`: путь не меняется от обновлений (Настройки →
   «Claude Desktop» → «Скопировать путь»). .NET для него не нужен. Для разработки можно собрать
   отдельно: `.\publish-mcp.cmd` → `publish\mcp\Xoard.Mcp.exe`.
2. Claude Desktop → Settings → Developer → **Edit Config** и добавить в `claude_desktop_config.json`:
   ```json
   {
     "mcpServers": {
       "xoard": {
         "command": "C:\\Users\\<имя>\\AppData\\Local\\Xoard\\mcp\\Xoard.Mcp.exe"
       }
     }
   }
   ```
   (если там уже есть другие серверы — добавить `"xoard": {…}` внутрь существующего `mcpServers`).
3. Перезапустить Claude Desktop, открыть Xoard и попросить, например: «включи звук аплодисментов».

Инструменты:

| Инструмент | Что делает |
|---|---|
| `list_sounds` | список звуков: id (имя файла), имя, длина, клавиша, играет ли |
| `play_sound` | сыграть звук (имя целиком или часть, либо id); `previewOnly` — только себе в наушники |
| `stop_all` | остановить все звуки |
| `set_volume` | громкость: headphones / cable / mic, 0–200 (100 — без изменений) |
| `set_hotkey` | назначить или снять клавишу: звуку, `stop_all`, `record`, `replay` |
| `start_recording` / `stop_recording` | запись трёх дорожек; общий звук — Discord + игра (`system`) или голос (`mic`) → новый звук, дорожки — в `Дорожки\` |
| `save_last_seconds` | сохранить последние N секунд повтора (все три дорожки вместе) как новый звук, дорожки — в `Дорожки\` |
| `rename_sound` | переименовать звук (файл) |
| `delete_sound` | удалить звук в корзину Windows |
| `trim_sound` | обрезать звук до [start, end) секунд, оригинал — в корзину |
| `get_status` | устройства, VB-CABLE, громкости, что играет, идёт ли запись, проблемы |

Если Xoard не запущен, Claude получит понятную ошибку «Xoard не запущен».
Если при обновлении Xoard сервер был занят Claude Desktop, новая копия ляжет при следующем запуске
Xoard (старая продолжает работать).

Протокол (`Xoard.Protocol`): одна строка JSON на запрос `{id, command, args}` и ответ
`{id, ok, result | error{code, message}}`. Команды выполняет `IXoardControl` — к нему же
позже подключится внешний (облачный) канал.

## Запуск приложения

```powershell
.\app.cmd
```

Собирает и запускает `Xoard.exe` (всё нужное лежит рядом с ним: .NET и Windows App SDK
ставить не надо). Звуки — `Документы\Xoard\Sounds` (папку можно сменить в настройках), настройки —
`%LOCALAPPDATA%\Xoard\settings.json`,
журнал сбоев — `%LOCALAPPDATA%\Xoard\crash.log`.

- Всё на одной странице. Три раскладки на выбор (Настройки → «Вид»): **Пульт** — звуки
  сеткой, справа запись и громкость; **Док** — крупные плитки, управление в плавающей панели снизу;
  **Лента** — одна колонка, звуки списком. Во всех — **живая волна последних 30 секунд** звука
  компьютера и кнопка «Сохранить».
- Настройки (шестерёнка) — окно поверх главного: разделы 01–09 слева (звук, клавиши, запись,
  вид, папка, VB-CABLE и Discord, запуск, обновления, Claude), содержимое справа. Esc или клик
  мимо окна — закрыть; при следующем открытии — тот же раздел.
- Вид: 11 палитр и «Авто» (днём Xoard, при тёмной теме Windows — Xoard ночь), по умолчанию —
  жёлтая Xoard; форма «Строгая» (почти прямые углы, тонкие линии) или «Мягкая», анимации — всё в
  настройках, меняется сразу. Шрифты Onest, Geologica и JetBrains Mono (цифры: время, клавиши,
  проценты) — SIL OFL, лежат рядом с программой.
- Клик по плитке — играть; правая кнопка — предпрослушать, клавиша, обрезать, переименовать,
  показать в папке, удалить в корзину. На плитке — волна звука, проигранная часть закрашивается.
- Файлы можно перетащить в окно (копируются в папку звуков); порядок плиток меняется перетаскиванием.
- Громкость: «Мне в наушники», «Звуки друзьям», «Мой голос» (+ выключение голоса) — от 0 до 200 %:
  100 % — как есть, выше — усиление до +12 дБ (ограничитель не даёт звуку хрипеть).
- Голос (Настройки → «Звук и устройства» → «Голос»): Xoard сам убирает шум (RNNoise) и выравнивает
  громкость речи — на 100 % голос звучит нормально с любым микрофоном, на 200 % — очень громко, у голоса
  свой ограничитель. Это заменяет обработку Discord, которую приходится выключать профилем «Студия»
  (она глушит звуки). Задержка голоса +20 мс. `rnnoise.dll` (RNNoise 0.2, BSD-3, лицензия рядом —
  `RNNoise-COPYING.txt`) собирается `src\Xoard.Core\Native\build-rnnoise.cmd` (нужен Zig).
- Папка звуков: Настройки → «Папка звуков» → «Выбрать другую…» — Xoard спросит, перенести звуки
  или просто переключиться; «Вернуть обычную» — снова `Документы\Xoard\Sounds`.
- Точка состояния в шапке показывает проблемы (нет VB-CABLE, вывод по умолчанию — кабель и т. п.).
- Горячие клавиши: правая кнопка по плитке → «Назначить клавишу…»; «Стоп всё», «Запись» и
  «Сохранить повтор» — в настройках.
  Работают в любой программе и в полноэкранных играх (RegisterHotKey, без перехвата клавиатуры —
  античиты не реагируют). Сочетание, занятое другой программой, назначить не даст — с объяснением.
- Запись и повтор идут **тремя дорожками**: **Discord** (голоса друзей), **Игра** (весь остальной звук
  компьютера, кроме Discord и Xoard: игра, браузер, музыка) и **Голос** (ваш голос, как его слышат друзья,
  после шумоподавления; при выключенном микрофоне — тишина). Сверху окна — три живые полосы. Повтор
  постоянно хранит последние 10–120 с (по умолчанию 30), только в памяти (около 17 МБ на 30 с).
  Xoard сам видит, какие программы звучат, и пишет каждую отдельной петлёй (Windows 10 2004+).
- Редактор клипа: после остановки записи и после «Сохранить» повтора из окна открывается волна
  с выделением (края по тишине обрезаны сами) — «Прослушать», «Сбросить выделение», «Выбросить»,
  «Сохранить целиком», «Сохранить выделенное». Под волной — дорожки с галочками: какие войдут в общий
  звук (он появится плиткой). Каждая непустая дорожка сохраняется отдельным WAV в папке
  `Дорожки\<имя>` внутри папки звуков (в список звуков они не попадают). Файлы появляются только
  после сохранения. Клавишей в игре и через Claude запись и повтор сохраняются сразу, без окна.
- Обрезка: правая кнопка по плитке → «Обрезать…» — тот же редактор, «Сохранить обрезку» (новый
  WAV, оригинал — в корзину) или «Отмена».
- Трей: кнопка ✕ прячет окно в трей — звуки, клавиши и Claude продолжают работать. Клик по
  значку — окно; правая кнопка — «Стоп всё», «Выключить голос», «Выход». В настройках можно
  сделать, чтобы ✕ закрывал программу.
- Автозапуск: Настройки → «Запуск и трей» → «Запускать вместе с Windows» (запись в
  `HKCU\…\CurrentVersion\Run`, без прав администратора; программа стартует свёрнутой в трей).
- Программа запускается в одном экземпляре: повторный запуск показывает уже открытое окно.
- Нет VB-CABLE — на главном экране сообщение со ссылкой на установку. «Как настроить Discord»
  (Настройки или значок состояния сверху; при первом запуске открывается само) проверяет,
  слушает ли Discord CABLE Output, и объясняет нужные настройки Discord.
- `XOARD_DATA_DIR=<папка>` — хранить настройки и звуки в другой папке (для проверок).

## Требования

- Windows 10 1809+ / Windows 11
- [VB-CABLE](https://vb-audio.com/Cable/) (бесплатный). Программа ищет его по имени драйвера
  «VB-Audio Virtual Cable», поэтому переименованные в настройках звука устройства тоже находятся.
- Устройство вывода **по умолчанию** в Windows — наушники/колонки, **не** CABLE Input,
  иначе весь звук компьютера (и голоса из Discord) попадёт в «микрофон».
- .NET 10 SDK для сборки

## Этап 0: Xoard.Poc

`poc.cmd` собирает и запускает PoC; .NET в PATH не нужен (SDK может лежать в `%USERPROFILE%\.dotnet`).
Запускать из папки проекта; `.\` в начале обязателен в PowerShell (в cmd тоже работает):

```powershell
.\poc.cmd list
.\poc.cmd selftest
.\poc.cmd play "C:\путь\к\звуку.mp3" --also-default
```

| Команда | Что делает |
|---|---|
| `list` | все устройства вывода/ввода, формат микширования, какое из них VB-CABLE |
| `selftest` | играет тон 1 кГц в CABLE Input и одновременно пишет CABLE Output: проверяет частоту, длительность, обрывы, уровень и примерную задержку |
| `tone` | тестовый тон в VB-CABLE |
| `play <файл>` | проигрывает файл в VB-CABLE (приводится к 48 кГц / float / стерео) |

Опции: `--device <часть имени>`, `--also-default` (ещё и в наушники), `--volume 0..1`,
`--seconds`, `--freq`, `--latency <мс>`.

### Проверка в Discord

1. Discord → Настройки → Голос и видео → **Устройство ввода: CABLE Output (VB-Audio Virtual Cable)**.
2. Там же профиль ввода — **«Студия»** (в остальных профилях шумоподавление, эхоподавление и автогромкость
   глушат звуки); чувствительность ввода — вручную, порог низкий.
3. Нажать «Проверка микрофона» и запустить `tone` — полоска уровня должна двигаться.
4. Позвонить другу и запустить `play` с mp3 — друг слышит звук.

## Этап 1: звуковой движок

```
Наушники (WasapiPlayer, MMCSS)        CABLE Input (WasapiPlayer, MMCSS, поток идёт всегда)
  звуки → микшер → громкость            звуки → микшер → + голос → громкость
        → лимитер −1 dBFS                     → лимитер −1 dBFS
                                       голос: WasapiRecorder → кольцо → ресемплер с подстройкой дрейфа
```

- Единый формат 48 кГц / float / стерео; звуки декодируются в память (до 10 мин, кэш 256 МБ).
- Голос с микрофона идёт **только** в VB-CABLE; CABLE Output движок никуда не выводит.
- VB-CABLE, «петлевые» устройства (Stereo Mix, Steam Streaming…) и CABLE Output никогда не
  выбираются автоматически как наушники или микрофон.
- Дрейф часов микрофона и VB-CABLE компенсируется ресемплером (ПИ-регулятор, ±2000 ppm).
- Своё приглушение звонками Windows отключено; один движок на пользователя (мьютекс).

```powershell
.\poc.cmd engine-devices                          # какие устройства выберет движок и что не так
.\poc.cmd engine --sounds "C:\Звуки"              # интерактивно: 1..0 — звуки, m — mute, h — справка
.\poc.cmd engine-selftest                         # автопроверка через VB-CABLE (без наушников и микрофона)
.\poc.cmd engine-selftest --load 12 --runs 3      # то же под нагрузкой на все ядра + давление на GC
```

`engine-selftest` не запускается, если CABLE Output сейчас кто-то слушает (Discord, OBS):
иначе собеседники услышат тестовые тоны. `--force` — запустить всё равно.

### Проверка этапа 1 (Discord)

1. Windows: устройство вывода по умолчанию — **наушники**, не CABLE Input
   (`engine-devices` предупредит, если это не так).
2. Discord → Голос и видео: ввод = **CABLE Output**; профиль ввода — **«Студия»**;
   чувствительность ввода — вручную, низкий порог.
3. `.\poc.cmd engine --sounds <папка>` → позвонить другу: говорить, запускать звуки поверх голоса,
   проверить наложение/перезапуск (`o`), «стоп всё» (пробел), ползунки (`q/a`, `w/s`, `e/d`).
4. В наушниках — только звуки, без собственного голоса; у друга — голос и звуки, без эха и хрипов.
5. `i` — статус: недогрузок голоса 0, дрейф захвачен, ошибок 0.

## Этап 5: запись, повтор, обрезка

- Три дорожки на одной шкале времени (`TrackTimeline`, 16 бит): **Discord** и **Игра** — петли
  процессов Windows (10 2004+), отдельная на каждую звучащую программу (`AppAudioCaptures`, раз в 2 с
  сверяется со звуковыми сессиями); Xoard, его потомки и предки (Проводник) не пишутся, программа,
  чей предок уже пишется, — тоже. **Голос** приходит от звукового движка после шумоподавления.
  На старых Windows пишется только голос.
- Повтор — кольцевой буфер в памяти (около 17 МБ на 30 с). По клавише в игре звук сохраняется
  молча, без окна; из окна сразу открывается редактор с дорожками.
- Записи сохраняются как WAV 48 кГц / 16 бит: общий звук — в папку звуков (плиткой), дорожки — в
  `Дорожки\<имя>`.
- `poc.cmd recording-selftest [--device <имя>] [--force]` — чужой тон попадает на «Игру», свой — нет.

### Проверка этапа 5

1. Включить видео в браузере → «Запись» → «Начать запись» → через несколько секунд «Остановить
   запись» → выделить нужный кусок → «Сохранить обрезку». Плитка появилась и играет.
2. Повтор включён → посмотреть видео → «Сохранить последние 30 с» (или клавиша повтора в игре) →
   новая плитка с последними секундами.
3. Запустить звук Xoard и сохранить повтор — звука Xoard нет ни в одной дорожке; в `Дорожки\<имя>`
   лежат `Discord.wav`, `Игра.wav`, `Голос.wav` (тихие дорожки не сохраняются).
4. Claude Desktop: «сохрани последние 10 секунд как „момент“» → «обрежь „момент“ с 2 по 5 секунду»
   → «назначь „момент“ на Ctrl+Alt+M».

## Этап 6: трей, автозапуск, VB-CABLE, Discord

- Значок в трее — свой код на Shell_NotifyIcon (без сторонних библиотек), на отдельном потоке;
  после перезапуска Проводника значок возвращается сам.
- `Xoard.exe --tray` — запуск без окна (так запускает автозапуск); звук, клавиши и канал
  для Claude работают сразу.
- Если автозапуск отключили в диспетчере задач, переключатель это показывает, а включение здесь
  возвращает запуск.

### Проверка этапа 6

1. Нажать ✕ — окно пропало, значок в трее остался; звук по горячей клавише играет.
2. Клик по значку — окно вернулось. Правая кнопка — «Стоп всё», «Выключить голос», «Выход».
3. Запустить Xoard ещё раз из ярлыка — открывается то же окно, второй копии нет.
4. Включить «Запускать вместе с Windows», перезагрузиться — Xoard в трее, клавиши работают.
5. Настройки → «VB-CABLE и Discord» → «Как настроить»: зайти в голосовой канал Discord — строка про Discord
   становится зелёной.
