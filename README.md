# Soundboard

Нативный саундборд для Windows: записывает звуки (с компьютера или микрофона) и проигрывает
их «в микрофон» через виртуальный кабель [VB-CABLE](https://vb-audio.com/Cable/), чтобы их
слышали в Discord и играх.

> Статус: **этап 0** — консольная проверка вывода в VB-CABLE.

## Требования

- Windows 10 1809+ / Windows 11
- [VB-CABLE](https://vb-audio.com/Cable/) (бесплатный). Программа ищет его по имени драйвера
  «VB-Audio Virtual Cable», поэтому переименованные в настройках звука устройства тоже находятся.
- Устройство вывода **по умолчанию** в Windows — наушники/колонки, **не** CABLE Input,
  иначе весь звук компьютера (и голоса из Discord) попадёт в «микрофон».
- .NET 10 SDK для сборки

## Структура

```
src/Soundboard.Poc        этап 0: консольная проверка
src/Soundboard.Protocol   (этап 4) DTO протокола управления
src/Soundboard.Core       (этап 1) звуковой движок, библиотека, конфиг, клавиши, pipe-сервер
src/Soundboard.App        (этап 2) интерфейс WinUI 3
src/Soundboard.Mcp        (этап 4) MCP-сервер для Claude Desktop
tests/Soundboard.Core.Tests
```

## Этап 0: Soundboard.Poc

`poc.cmd` собирает и запускает PoC; .NET в PATH не нужен (SDK может лежать в `%USERPROFILE%\.dotnet`).
Запускать из папки проекта; `.\` в начале обязателен в PowerShell (в cmd тоже работает):

```powershell
.\poc.cmd list
.\poc.cmd selftest
.\poc.cmd play "C:\путь\к\звуку.mp3" --also-default
```

| Команда | Что делает |
|---|---|
| `list` | все устройства вывода/ввода, формат микширования, какое из них VB-CABLE |
| `selftest` | играет тон 1 кГц в CABLE Input и одновременно пишет CABLE Output: проверяет частоту, длительность, обрывы, уровень и примерную задержку |
| `tone` | тестовый тон в VB-CABLE |
| `play <файл>` | проигрывает файл в VB-CABLE (приводится к 48 кГц / float / стерео) |

Опции: `--device <часть имени>`, `--also-default` (ещё и в наушники), `--volume 0..1`,
`--seconds`, `--freq`, `--latency <мс>`.

### Проверка в Discord

1. Discord → Настройки → Голос и видео → **Устройство ввода: CABLE Output (VB-Audio Virtual Cable)**.
2. Там же выключить: шумоподавление (Krisp), эхоподавление, автоматическую регулировку усиления;
   чувствительность ввода — вручную, порог низкий.
3. Нажать «Проверка микрофона» и запустить `tone` — полоска уровня должна двигаться.
4. Позвонить другу и запустить `play` с mp3 — друг слышит звук.
